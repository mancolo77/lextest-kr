# LexTest КР — Интерактивная система тестирования для кандидатов в судьи КР

Современный веб-тренажер и симулятор квалификационного экзамена для кандидатов на должности судей Кыргызской Республики.
База данных содержит **4 332 официальных вопроса** по **21 отрасли права**.

## 🎯 Основные режимы работы

1. **🎯 Квалификационный экзамен**:
   - Симуляция реального тестирования с таймером (настраивается: 25, 50, 100 или 150 вопросов).
   - Проходной балл — **70%** (в соответствии с регламентом).
   - Сбалансированная выборка вопросов пропорционально из всех 21 тем.
   - Итоговый подробный отчет с разбором правильных и ошибочных ответов.

2. **📚 Тренировка по темам**:
   - Выбор одной или нескольких из 21 отраслей права.
   - Мгновенная проверка ответа (зеленый / красный) и пояснения.
   - Показ прогресса освоения по каждой теме.

3. **⚡ Марафон до 3 ошибок**:
   - Проверка на выносливость с 3 жизнями и множителем серии верных ответов.
   - Фиксация личного рекорда.

4. **🔍 База вопросов и мгновенный поиск**:
   - Поиск по всей базе (4 332 вопроса) по тексту вопроса или вариантам ответов.
   - Фильтрация по отраслям права.
   - Возможность скопировать вопрос в один клик.

5. **📊 Статистика и Банк ошибок**:
   - Автоматическое сохранение вопросов с ошибками в **«Банк ошибок»**.
   - Кнопка **«Тренировать только ошибки»** для целевой отработки сложных вопросов.
   - Сохранение в «Избранное» (⭐) любых вопросов.
   - Графики уровня освоения по всем 21 отраслям права.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| `1`, `2`, `3`, `4` | Выбор варианта ответа (A, B, C, D) |
| `Enter` или `→` | Перейти к следующему вопросу |
| `←` | Вернуться к предыдущему вопросу |
| `F` | Пометить вопрос флажком для повторной проверки |
| `B` | Добавить в избранное |
| `Esc` | Закрыть модальное окно |

## 📁 Структура файлов проекта

- **`index.html`** — разметка интерфейса и режимов.
- **`style.css`** — стили, темная/светлая темы, адаптивный дизайн для ПК и мобильных.
- **`app.js`** — движок тестирования, синтезатор звуков, таймер, поиск, аналитика.
- **`questions.js`** / **`questions.json`** — структурированная база 4 332 вопросов, спарсенная из `test.docx`.
- **`test.docx`** — исходный документ.
